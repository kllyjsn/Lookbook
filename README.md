# LOOKBOOK (LKBK)

A fashion discovery and personal styling app with magazine aesthetics and Tinder-like swipe mechanics.

## Features

- **Style Discovery** — Swipe through editorial fashion looks (right to love, left to pass, up to shop)
- **Shop the Look** — Upload any image and find similar items across shops
- **Event Stylist** — Get personally styled for any occasion
- **Capsule Wardrobe** — Build a complete mix-and-match wardrobe from scratch
- **Style Profile** — Track your style DNA, saved looks, and collections

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Zustand
- Lucide Icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
